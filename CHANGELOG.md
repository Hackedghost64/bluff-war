# Changelog

## [1.1.0] - 2024-05-15
### Added
- **WAR MODE**: New high-stakes gameplay mechanics.
- **Escalating Damage**: Damage increases with every "Believe".
- **Limited Believes**: Players only get 3 "Believes" per game.
- **HP for Truth**: Reward players with +1 HP for correctly believing a truth.
- **Visual Effects**: Added screen shake, red flash, and pulsing turn indicators.
- **Card Animations**: Cards now slide and scale onto the field.
- **Auto-Updater**: Support for automatic update notifications via GitHub Releases.
- **New Branding**: Renamed app to "BLUFF WAR" with a new crossed-swords icon.

### Fixed
- Fixed bug where turns wouldn't swap because the active card wasn't clearing.
- Fixed bug where playing identical cards removed the entire hand.
- Streamlined connection flow to bypass redundant Host/Join screens.
- Fixed "How to Play" button to work during active gameplay.
